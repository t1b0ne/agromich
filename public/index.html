1. Requisitos Previos

Antes de desplegar el servidor backend, asegúrate de cumplir con los siguientes requerimientos de entorno:

  • Python 3.10+ instalado en el sistema operativo.
  • Google Earth Engine API: Cuenta y autenticación previa mediante credenciales CLI locales.
  • Google Chrome y ChromeDriver: Obligatorio para los bots de web scraping del SIAP.

2. Guía de Instalación Paso a Paso

# 1. Clonar el repositorio y entrar

cd agromich

# 2. Crear entorno virtual

python -m venv venv

venv\Scripts\activate

# 3. Instalar librerías

pip install -r requirements.txt

# 4. Iniciar servidor FastAPI

uvicorn app.main:app --reload --port 8000

3. ¿Qué estamos instalando?

FastAPI & Uvicorn

Framework web de alto rendimiento para APIs asíncronas.

Google Earth Engine & Auth

6. Ejemplo de Consumo

import requests

url = "http://localhost:8000/api/v1/expediente/generar-completo"
payload = {
    "nombre_huerto": "Huerta San José",
    "productor": "Juan Pérez",
    "municipio": "Uruapan",
    "cultivo": "aguacate",
    "geometry": {
        "type": "Polygon",
        "coordinates": [[[-102.1, 19.4], [-102.0, 19.4], [-102.0, 19.5], [-102.1, 19.5], [-102.1, 19.4]]]
    },
    "anio_inicio": 2022,
    "anio_fin": 2026
}
response = requests.post(url, json=payload)
print(response.json())
