Inicio rápido

La API se ejecuta en http://localhost:8000. La especificación interactiva está en /docs y el estado básico en /api/v1/sistema/salud.

python -m venv venv
venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
Importante: las rutas costosas requieren X-API-Key si se definió AGROMICH_API_KEY en el archivo .env.

app/ ├── main.py # FastAPI y registro de rutas ├── routers/ # Controladores HTTP ├── schemas/ # Contratos y validaciones Pydantic ├── services/ # Lógica agronómica y geoespacial ├── integrations/ # NASA POWER y Google Earth Engine ├── repositories/ # Persistencia segura de reportes ├── core/ # Configuración, API key y GEE └── api/v1/routers/ # Adaptadores de versionado reports/ ├── clima_avanzado/ # Salidas climáticas ├── suelo_y_socioeconomico/ # SIAP ├── sanidad_y_programas/ # Sanidad y programas └── generados/ # Descargas HTML/PDF

API y validación

FastAPI recibe JSON, Pydantic valida fechas, rangos, cuerpos y geometrías GeoJSON.

Servicios externos

GEE aporta imágenes y métricas; NASA POWER aporta clima; SIAP se consulta con Selenium.

Resultados

Los servicios devuelven JSON y pueden persistir respaldos que el módulo de reportes consolida.

Configuración y seguridad

AGROMICH_API_KEY=una-clave-larga-y-secreta
EARTHENGINE_PROJECT=agromich-507422
GEOVIGIA_ORIGINS=http://localhost:5173,https://tu-dominio.com

Use el encabezado X-API-Key: tu-clave en análisis, expedientes y reportes. Las rutas de salud son públicas. Nunca publique .env, credenciales OAuth ni reportes con datos de productores.

Análisis satelital

POST /api/v1/satelite/analisis. Las coordenadas GeoJSON siempre son [longitud, latitud].

curl -X POST http://localhost:8000/api/v1/satelite/analisis \
  -H "Content-Type: application/json" -H "X-API-Key: tu-clave" \
  -d '{"geometry":{"type":"Polygon","coordinates":[[[-102.065,19.412],[-102.055,19.412],[-102.055,19.422],[-102.065,19.422],[-102.065,19.412]]]},"cultivo":"aguacate","fecha_inicio":"2020-01-01","fecha_fin":"2025-12-31"}'

Expediente ambiental e imágenes

POST /api/v1/expediente/generar-completo genera la auditoría ambiental. POST /api/v1/expediente/imagenes-historicas recibe geometry, anios, cultivo, mes_inicio y mes_fin.

curl -X POST http://localhost:8000/api/v1/expediente/generar-completo \
  -H "Content-Type: application/json" -H "X-API-Key: tu-clave" \
  -d '{"nombre_huerto":"Huerta San Jose","productor":"Productor Ejemplo","municipio":"Uruapan","cultivo":"aguacate","geometry":{"type":"Polygon","coordinates":[[[-102.065,19.412],[-102.055,19.412],[-102.055,19.422],[-102.065,19.422],[-102.065,19.412]]]},"anio_inicio":2018,"anio_fin":2025}'

Reportes y descargas

El servicio de reportes consolida las fuentes disponibles: clima, suelo, sanidad y procesados. El archivo se devuelve en la respuesta y se guarda en reports/generados/.

curl -X POST http://localhost:8000/api/v1/reportes/generar \
  -H "Content-Type: application/json" -H "X-API-Key: tu-clave" \
  -d '{"titulo":"Reporte integral Uruapan","estado":"Michoacan de Ocampo","municipio":"Uruapan","servicios":["clima","suelo","sanidad"],"incluir_historial":false,"formato":"pdf"}' \
  --output reporte-uruapan.pdf
# Listar archivos y descargar uno
curl -H "X-API-Key: tu-clave" http://localhost:8000/api/v1/reportes
curl -H "X-API-Key: tu-clave" \
  "http://localhost:8000/api/v1/reportes/NOMBRE_DEL_ARCHIVO.pdf/descarga" \
  --output reporte.pdf

Operación, errores y límites

Estados HTTP

200 éxito · 401/403 API key · 422 JSON, fecha o GeoJSON inválido · 502 proveedor externo · 503 dependencia no disponible.

Buenas prácticas

No incluya secretos en clientes web. Limite el tamaño de los polígonos. Muestre carga para SIAP/GEE. Trate las señales satelitales como insumos de revisión, no como una resolución legal.
